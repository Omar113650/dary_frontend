# DARY Brand Assets

This folder contains the official **DARY** (داري) brand assets.

## Contents

The official DARY logo and any approved brand materials should be placed in this directory.

## Usage

- Use only the official logo files provided here.
- Do not recreate, modify, or substitute the logo.
- Refer to this folder as the single source of truth for all DARY branding.
